# commands/

Placeholder. Legacy way to define skills as flat Markdown files at this
plugin's source root. New skills should use `skills/<name>/SKILL.md` instead
(see [`template/`](../../../template) at the repo root); this folder is kept
as a reserved spot in case a plain slash-command style skill is ever needed
for `grill-me`.

Not used yet. See the
[plugin structure reference](https://code.claude.com/docs/en/plugins-reference).
